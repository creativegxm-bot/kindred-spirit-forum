# ondabir

Toplulukların Buluşma Noktası - Topluluklar, paylaşımlar ve tartışmalar

## Proje Hakkında

ondabir, kullanıcıların topluluklar oluşturabileceği, paylaşımlar yapabileceği ve tartışmalara katılabileceği modern bir sosyal platform uygulamasıdır.

## Kullanılan Teknolojiler

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase (Backend)

## Özellikler

- 🏠 Topluluklar oluşturma ve yönetme
- 📝 Gönderi paylaşma ve oylama
- 💬 Yorum yapma ve tartışma
- 🔔 Bildirim sistemi
- 💾 Kayıtlı gönderiler
- 🌐 Çoklu dil desteği (Türkçe/İngilizce)
- 🎨 Karanlık tema
- 📱 Mobil uyumlu tasarım
